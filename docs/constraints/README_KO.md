# 제약·계약 문서 카탈로그

이 폴더는 프로젝트의 제약, gate, privacy/license, 실행 계약, 승인 및
재현성 정본 문서를 한 곳에 모아 관리하는 영역이다. 이동된 정본의 경로는
`docs/constraints/`로 통일했으며, 코드·config·인수인계 문서의 참조도 함께
갱신했다. 데이터·checkpoint·secret은 이 폴더에 포함하지 않는다.

## 정본 우선순위

1. 사용자의 현재 요청
2. `.codex/ai_rule_developer/` 규칙
3. `docs/constraints/`의 계약·상태 문서
4. `.codex/ref_docs/` 참고자료

## 운영 원칙

- 계획·정적 준비·실제 실행·사람 평가를 서로 바꾸어 기록하지 않는다.
- 선행 gate, label/QC/privacy/license/split/hash를 확인하지 못하면
  fail-closed로 멈춘다.
- 사람 평가 문서는 삭제하거나 AI 수행 완료로 바꾸지 않는다. AI가 만든
  준비물은 `AI 준비 완료`로만 기록하고 실제 동의·청취·전문가 판정은
  별도 gate로 유지한다.
- AI Hub 원본·파생 음성·제한 manifest·checkpoint·secret은 이 카탈로그에
  복사하지 않는다.
