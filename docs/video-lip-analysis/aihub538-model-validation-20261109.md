## 정량 평가 방법

측정값은 눈 사이 거리로 정규화한다. 벌림은 모음 구간의 관측된 4개 위상별 중앙값,
원순 형상은 정면 입술 폭, 폐쇄는 양순음 구간의 최소 관측 벌림,
타이밍은 실제 변화가 관측된 구간의 사건 위치다. 정면 폭으로 3D 입술 돌출을 추정하지 않는다.

화자별 평균에 같은 가중치를 주고 화자 간·화자 내 분산을 함께 반영한다.

```text
μ = 화자별 평균의 평균
σ² = 화자별 평균의 표본분산 + 화자별 표본분산의 평균
z = (사용자 측정값 − μ) / sqrt(σ²)
점수 = 100 × exp(−0.5 × z²)
```

측정 방식·MediaPipe 모델 SHA·landmark 매핑·품질 설정이 맞는 자료끼리만 비교한다.
정적 형상은 실제 1프레임, 폐쇄는 최소 2프레임, 타이밍은 최소 3프레임과 실제 움직임을 요구한다.
프레임 복제·가짜 시간 정렬·없는 참조 대체는 하지 않는다.
계산된 위상→성분→음소 점수를 합산하며, 미평가 음소를 0점 또는 만점으로 채우지 않는다.

이 점수는 **참조 분포와의 유사도**다. 100점은 정확한 발음의 보증이 아니며,
낮은 점수도 오발음의 확정 근거가 아니다. 원본 데이터에 입술 오류·전문가 교정 점수의
정답 라벨이 없어 정오 판별 정확도·민감도·특이도를 검증하지 못했다.

## 화자 분리 일반화 검사

3회 leave-one-speaker-out: 매회 2화자로 다시 학습하고 완전히 제외한 1화자를 비교했다.
아래 비율은 비교 가능한 **관측값** 중 참조 평균의 ±2SD에 포함된 비율이며 발음 정답률이 아니다.
반복 프레임은 독립 화자 수로 세지 않았다. fold별 표본 수는 크게 다르다.

| 제외 화자 fold | 벌림 관측 수 / ±2SD 비율 | 폭 형상 관측 수 / ±2SD 비율 | 폐쇄 관측 수 / ±2SD 비율 |
|---|---|---|---|
| 0 | 1974 / 98.7% | 245 / 58.4% | 124 / 95.2% |
| 1 | 128 / 99.2% | 14 / 85.7% | 9 / 100.0% |
| 2 | 267 / 84.3% | 28 / 100.0% | 15 / 86.7% |

폭 형상은 fold 0의 평균 절대 z가 2.00으로, 벌림 0.75보다 화자 변화에 민감했다.
3화자·60문장의 소규모 자료로 사람의 얼굴 구조·공조음·속도 차이를 충분히 분리하지 못한다.
새 화자와 전문가 오류 라벨을 확보해 임계값·점수 해석을 검증해야 운영용 정확성 점수로 사용할 수 있다.
