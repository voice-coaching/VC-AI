# 영상 입술 채점과 피드백 연결 실행 계획

기준일: 2026-11-06. 상태: 연구 기반 설계안. 관련 논문은 [문헌 검토](lip-research-review-20261106.md), 수집 파일은 [manifest](../../literature/lip-analysis-20261106/manifest.json)에 있다.
이 문서는 현재 구현 사실, 재사용할 코드, 새로 검증할 제안을 구분한다. 이번 작업에서 서비스·모델·프롬프트를 수정하거나 실제 분석·학습·배포를 실행하지 않았다.

## 1. 목표와 고정할 원칙

영상에서 **보이는 입술 조음의 참조 적합성**을 0~100점으로 산출하고, 기존 음성 6항목 점수와 결합한다.
영상 요청에서는 유효한 입술 근거가 충분할 때 입술 교정을 우선 안내한다.

- Seungun 원본 JSON과 원본 음성·영상은 바이트 그대로 보존한다. 시각 근거·시간 정렬·검산표는 별도 자료로 만들고 원본 해시와 연결한다.
- 기존 음성 6항목의 계산식·배점·발음 채점표를 유지한다. 입술 점수 때문에 기존 음성점수를 다시 매기지 않는다.
- 서버가 측정·채점·피드백 대상을 선정하고 GPT는 제공된 점수와 허용 행동을 설명한다. 요청당 GPT API 호출은 최대 1회이며 자동 재호출하지 않는다.
- 기존 공개 `score.overallScore` 이름과 기존 외부 envelope를 유지한다. 프론트·백엔드에서 공식 검산표를 다시 검증하지 않는다.
- 영상의 관측 실패 때문에 정상적인 음성 분석 전체를 중단하지 않는다. 파일 불일치·잘못 연결된 다른 시도의 영상은 관측 실패와 구분한다.
- 사용자 피드백은 최대 3개 연습 항목·전체 5문장 이내라는 기존 제한을 유지한다.

2026-11-05 소스·운영·배포된 프론트 정적 파일 조사에서 확인한 상태다. 이번 문헌 조사 시각에 전체 운영 상태를 다시 검사한 것은 아니다.

| --- | --- | --- | --- |
| 벌림·입구 형상 | 안쪽 입술 간 거리, 입구 폭·면적, 윤곽의 시간 변화 | 참조와 전문가 검수가 확보된 모음·문맥 | 모든 모음·자음을 같은 벌림 평균으로 평가하지 않음 |

| 동작의 시간 관계 | 폐쇄·열림 event의 상대 시각과 연속 궤적 | 실제 PTS·MFA·미디어 시간 연결이 확인된 구간 | 소리와 0ms 일치를 정상 목표로 사용하지 않음 |

P04는 시각 범주의 다대일 문제, P07·P08은 한국어 문맥·속도 변이, P15·P16은 자연 시차를 다룬다.
평가 대상은 카메라에 보이는 동작으로 한정하고, 발음 전체의 정확성은 기존 음성 근거와 함께 해석한다.

## 4. 처리 흐름

```text
실제 영상 업로드 + 같은 녹음의 음성 + 원고
  → 기존 Backend 미디어 준비: 영상·PCM·시간 출처 결속
  → 병렬 실행
      A. 기존 Seungun CORE → 원본 JSON 그대로 보존 → 기존 음성 6항목 점수 A
      B. 영상 PTS·얼굴/입술 추적 → 품질 관측·입술 특징열
  → 실제 MFA 구간을 별도 근거로 연결 → 음소·문맥별 입술 비교
  → 입술 점수 L·평가 범위·허용 교정 행동 → 영상 종합점수 V
  → 입술 우선 피드백 대상 선정
  → 원본 Seungun JSON + 별도 음성/시각 근거·검산표 → GPT 요청 1회
  → 기존 overallScore와 feedback 전달 + 기존 visual 영역에 입술 근거
```

원본 JSON의 필드 선택·요약·재인코딩으로 GPT 입력을 대체하지 않는다.
영상의 RGB 전체나 전체 얼굴 mesh를 GPT에 보내는 방식은 기본안에 포함하지 않는다.
GPT 입력은 원본 CORE 메시지와 별도 시각 측정·허용 행동 메시지로 구성하며 한 completion 요청에 함께 넣는다.

### 시간 정렬

1. 현재 음성 실행이 실제로 만든 TextGrid/MFA 산출물에서 시간 정보를 읽는다. 소스 artifact 해시, 요청·실행 ID, 원본/준비 PCM 해시와 연결한다.
2. 원고 표지, GOP 표본, 실제 정렬의 index namespace를 분리한다. 서로 표본 수가 다르다는 이유로 생략을 만들어 내거나 전체 채점을 중단하지 않는다.
3. 시각 정렬은 별도 자료에 `expectedPhone`, `role`, 문맥, 원본 음소 index, 오디오 구간, 비디오 PTS·관측 프레임 수·정렬 출처를 저장한다. CORE에 가상 `mfa_phone_alignment`를 끼워 넣지 않는다.
4. MFA 음향 구간을 입술 동작의 정확한 시작·끝으로 간주하지 않는다. P15에 따라 준비 동작과 연속 동작을 구분하고 참조도 같은 event 정의로 추출한다.
5. 목표 구간과 전후 문맥 프레임을 구분한다. 전후 프레임을 추가로 봐도 목표 음소 내부의 실제 관측 수로 부풀리지 않는다. 문맥창 범위는 개발 자료에서 고정하고 정답을 찾기 위해 무제한 이동하지 않는다.
6. 불확실한 구간은 해당 음소의 시각 평가만 제한하고 나머지 음소와 음성 점수는 유지한다. 보간 프레임을 새 관측 증거로 세지 않는다.

## 5. 참조와 전문가 자료 구축

### 자료의 역할

- 사용자 지정 전문가 영상 `tests/testvideo1.mp4`는 해당 원고·구간의 첫 참조 후보로 사용한다. 영상·대본 일치와 적합한 구간은 실제 확인하며, 한 영상으로 모든 한국어 정상 기준을 만들지 않는다.
- P10 OLKAVS 같은 한국어 음성·영상 자료는 정상 변이·추출기·표현 학습 후보로 검토한다. 전문가의 오류·교정 라벨이 있다고 가정하지 않는다. 이번 작업에서는 데이터셋을 다운로드하지 않았다.
- 실제 제품 화자·기기 조건의 녹화와 독립 전문가 평정을 추가한다. legacy 공통 벌림 평균을 음소별 정답으로 채우지 않는다.

### 파일럿의 구체적인 시작안

초기 설계치는 참조 화자 12명과 학습자 18명, 목표 문맥을 포함한 12문장, 편안한 속도·빠른 속도, 각 2회다.
총 `30 × 12 × 2 × 2 = 1,440`개 클립이다. 이는 논문이 보장한 충분 표본 수가 아닌 모집·비용 산정을 위한 시작안이며, 첫 자료의 오차·화자 간 분산과 필요한 신뢰구간을 보고 증감한다.

- 각 문장의 검수 대상 음소·역할·앞뒤 소리·단어 경계·속도 조건을 미리 정한다.
- 최소 3명의 한국어 음성 전문가가 모델 점수를 보지 않고 독립 평가한다. 첫 단계는 무음 영상의 '보이는 입술 동작 적절성', 다음 단계는 음성·영상을 함께 본 교정의 적합성이다.
- 평가표는 적절성 0~4단계, **관측 불가**, 허용된 다른 발화 형태, 차이의 방향, 교정 행동, 동작 시간의 불확실성을 분리한다. 관측 불가를 0단계로 만들지 않는다. 단계별 행동 기준은 전문가와 먼저 합의한다.
- 동일 화자의 모든 문장·반복·속도·기기는 같은 데이터 분할에 둔다. 참조 적합·보정 학습·검증·최종 테스트를 분리하고 테스트 화자가 기준 분포에 섞이지 않게 한다.
- 데이터가 적은 음소·문맥은 넓은 범주로 임의 대체하지 않는다. 전문가가 인정한 공유 범주만 사용하고 적용 범위·표본 수를 기록한다.
- 현재 단계는 해당 평가표·모집 설계의 준비이며, 전문가 평정이나 실제 실험을 이미 수행했다는 뜻이 아니다.

## 6. 채점 수식 후보

### 6.1 좌표와 특징

머리의 평행 이동·크기·roll을 눈/얼굴 기준으로 보정한다. 입술의 현재 폭을 매 프레임 정규화 분모로 사용해 원순 동작 차이를 지워 버리지 않는다.
큰 회전·가림·검출 흔들림은 품질 정보로 남기고 추정 z값을 mm 단위 실측 돌출량으로 해석하지 않는다. P05의 RGB-D 결과와 P13의 근사 mesh를 구분한다.

기하 특징 후보는 `aperture`, `width`, `innerArea`, 검수된 윤곽 표현이다. 전이·폐쇄 event는 별도 시간 특징이다.
공통 특징 중복으로 벌림을 여러 번 가중하지 않도록 상관·안정성을 분석해 선택한다.

### 6.2 음소·문맥별 거리

목표 음소·역할·문맥·속도 조건을 `p,c`라 하자. 해당 조건의 허용 참조 집합 안에서만 비교한다.
정규화 특징의 local cost 후보는 다음과 같다.

\[
d(x,y)=\frac{(f(x)-f(y))^T\Sigma_{p,c,reg}^{-1}(f(x)-f(y))}{k}.
\]

`Σ`는 개발 참조에서 얻고, 안정적으로 추정할 수 없는 조건은 대각/shrinkage 기준 모델과 비교한다.
행렬을 계산할 수 있도록 임의의 화자 자료를 보충하거나 0분산을 숨기지 않는다.
이 공분산 거리와 landmark 적용은 **프로젝트의 검증 가설**이며 P02 원문 수식을 그대로 구현한 것이 아니다.

시간 변화 비교는 P02를 참고한 제한 WDTW 후보를 사용한다.

\[
D_{ir}=\frac{\sum_{(a,b)\in\pi^*}w(|u_a-v_b|)d(x_a,y_b)}{|\pi^*|}.
\]

`π*`는 제한된 단조 경로에서 **가중 누적 비용**을 최소화한 경로다. 평균 비용 자체를 최소화하는 다른 알고리즘과 혼용하지 않는다.
과도한 warping으로 느린 폐쇄·다른 음소·잘못된 동작을 정상으로 맞추지 않으며 실제 event 시간·길이는 별도 보존한다.
여러 정상 발화 모드가 있으면 모드를 먼저 구분하고, 모드 내 참조 거리의 중앙값 등 고정 규칙을 사용한다. 매번 가장 비슷한 참조 하나만 골라 100점을 만들지 않는다.

### 6.3 초기 연구 점수와 공개 입술 점수

초기 연구 점수 후보:

\[
S_i^{raw}=100\exp(-\lambda D_i).
\]

공개 평가용 점수 후보:

\[
S_i^{lip}=g_{p,c}(D_i),\quad 0\le g\le100.
\]

`g`는 독립 전문가 평정으로 맞춘 단조 보정 함수다. isotonic과 단순 단조 회귀를 개발 자료에서 비교한다.
임시 `S_raw`를 검증된 정확도나 오류 확률로 부르지 않는다. 미보정 단계는 연구용 유사도로 보관하고, 전문가와 일치하는 공개 점수의 근거로 대체하지 않는다.

지표 하나만 먼저 사용하는 초기 기준 모델은 다음처럼 허용 범위를 둘 수 있다.

\[
z_i=\max(0,|x_i-\mu_{p,c}|-r_{p,c})/s_{p,c},\qquad
S_i^{raw}=100\exp(-\lambda z_i^2).
\]

이는 평균 부근의 허용 변이를 불필요하게 감점하지 않는 **제안**이다. `μ,s,r`는 음소·문맥별 개발 자료와 전문가 정의로 정하고 `s>0`을 확인한다. 모든 음소에 같은 평균을 적용하지 않는다.

### 6.4 문장 입술 점수와 coverage

\[
L=\frac{\sum_{i\in E}w_iS_i^{lip}}{\sum_{i\in E}w_i}.
\]

초기 `w_i=1`로 occurrence별 동일 비중을 사용한다. 긴 모음·한 프레임의 높은 confidence가 자동으로 점수를 지배하지 않게 한다.
총 목표 수·지원 가능한 시각 목표 수·관측 수·실제 채점 수를 구분하고 coverage를 함께 제공한다.
관측 불가·미지원 음소를 정상/오류 점수로 채우지 않는다. 카메라 신뢰도를 점수에 곱해 발음 감점으로 사용하지 않는다.

대표성이 부족하면 입술 전체 점수를 보류하고 국소 관측만 제공할 수 있다. 보류하더라도 기존 음성 점수 A는 유지한다.
coverage 기준은 오류/보류율을 보고 전문가와 정하며 전체 녹음을 무조건 취소하는 게이트로 사용하지 않는다.

### 6.5 영상 종합점수

가중치의 시작 제안은 다음과 같다.

\[
V=0.60A+0.40L.
\]

- `A`: 기존 6항목 음성 종합점수. 발음 정확성의 기존 9항목 검산표도 그대로 유지한다.
- `L`: 위 기준으로 계산·보정한 입술 점수. `V`의 60:40은 논문의 결론이 아닌 제품 정책 후보다.
- 음성 전용은 기존 `overallScore=A`다. 입술 점수를 평가하지 않은 과거 기록에 새 비중을 소급 적용하지 않는다.
- 영상에서 L을 만들 수 없으면 A를 유지하면서 **음성 점수 / 입술 평가 불가**로 명확히 표시한다. A만 있는 결과를 완전한 영상 종합점수로 표시하지 않는다.
- 최종 가중치·coverage 기준은 전문가의 영상 전체 평가와 민감도 분석으로 선택한다. 같은 조음 현상이 음성 정확성과 입술에 중복 반영되는 영향도 평가한다.

원본 `RUBRIC_RESULT`와 음성 `COMPOSITE_RESULT`는 보존하고 별도 `VIDEO_COMPOSITE_RESULT`를 둔다.
기존 음성 검산값을 영상 점수로 덮어쓰지 않는다. 공개 투영에서만 해당 모드의 최종값을 기존 `score.overallScore`로 전달한다.

## 7. 점수에서 사용자 피드백으로 연결

낮은 점수·큰 거리만으로 '더 벌리기/덜 벌리기'가 결정되지는 않는다.
교정 대상은 아래 정보를 모두 갖춘 경우에 선정한다.

- 원고의 단어·실제 음소 위치와 같은 영상 구간의 근거 ID.
- 측정 가능한 특징의 차이 방향, 허용 범위, 조건에 맞는 전문가 action mapping.
- 화자·기기·프레임 품질과 시간 근거가 해당 행동을 지지하는지에 대한 상태.
- 입술로 관찰할 수 없는 혀·성대·비강 상태를 추정하지 않는 판정 범위.

### 대상 선정 제안

1. 영상 요청에서 독립적인 유효 입술 교정 대상이 2개 이상이면 최대 3개 중 2개를 입술에 우선 배정하고 나머지 1개는 기존 음성 기준에서 선정한다.
2. 입술 대상이 1개면 1개만 배정한다. 같은 단어·같은 동작을 두 개로 쪼개 할당량을 채우지 않는다.
3. 유효한 입술 교정 대상이 없으면 오류를 만들어 내지 않고 기존 음성 피드백과 관측 상태를 제공한다. 촬영 안내는 발음 결함 주장과 구분한다.
4. 우선순위는 차이의 크기·근거 신뢰성·연습 가치·대상 중복 여부를 함께 고려한다. 근거 신뢰성은 **선정**에 사용하고 점수에 임의로 곱하지 않는다.
5. 음성·입술 판단이 충돌하면 각각의 범위를 유지한다. 시각적으로 비슷하다는 이유로 음향 오류를 취소하거나, 음향 오류만으로 입술 동작 오류를 생성하지 않는다.

GPT에는 서버가 고른 최대 3개의 `feedbackTargets`, 근거 ID, 허용 행동·금지 주장, 최종 점수를 제공한다.
단어·짧은 구간을 지목하고 사용자가 실행할 행동 하나를 쉬운 문장으로 안내한다. 내부 거리·표준편차·GOP·confidence 숫자는 사용자 연습문에 노출하지 않는다.
문구의 특정 좋은 예시를 강제 복제시키는 대신 대상·행동·길이 규칙과 근거 범위를 시스템 프롬프트로 제약한다.

P05·P06의 시각 시연은 후속 기능 후보다. 첫 출시의 핵심을 3D 아바타 생성으로 확장하지 않는다.

| F. 출시 후보 | 기존 음성 회귀와 실제 영상·장애 입력·deadline·부하 확인 후 PR | 정확한 source tree·CORE/H5·fixture 해시에 묶인 통과 기록. 별도 배포 승인과 rollback 자료 |

### 검증 항목

- **측정:** 전문가 landmark/event 표본과의 오차, 실제 프레임·PTS, pose·가림·저조도·카메라 변화. 장치 offset과 생리적 동작 차이를 분리.
- **채점:** 전문가 간 일치도, Spearman·MAE·절대 일치도 ICC, calibration 오차, 화자/기기별 오차와 bootstrap 신뢰구간. 샘플별 임의 점수 기준이 아닌 고정된 held-out 집합 사용.
- **기준 비교:** 공통 벌림 평균, 음소별 정적 기준, 문맥별 DTW, 전문가 보정 모델을 비교. 음성만으로도 나오는 성능과 영상이 추가한 성능을 구분.
- **피드백:** 행동 방향 정확성, 근거 없는 주장, 유효 대상 비율, 동일 오류 중복, 5문장 제한. 목표는 높은 점수와 교정 효과를 각각 확인하는 것.
- **학습:** 동일 연습량의 음성 피드백과 입술 우선 피드백을 비교하고 다른 문장·지연 재검사에서 전문가가 변화량을 평가. 설문 만족도를 발음 향상으로 대체하지 않음.
- **회귀:** 기존 음성 사례의 점수·원본 JSON 바이트가 유지되는지, 영상 오류가 음성점수를 지우지 않는지, 각 요청 GPT POST가 1회인지 확인.

전문가 간 신뢰도가 낮거나 참조 거리와 전문가 판단이 일치하지 않으면 점수 보정·평가 범위를 수정한다.
부정확한 입술 기준을 가중해 '영상 종합점수'를 먼저 배포하지 않는다.
PR 생성 전 실제 분석 검사는 프로젝트 AGENTS의 음성 회귀 절차에 영상 사례와 같은 시도의 v4→v6/handoff·Backend/Frontend 점수 연결을 추가한다.
기존 운영 사용자 작업을 자동 재실행하거나 실패 이력을 덮어쓰는 방식으로 검사하지 않는다.

## 11. 운영 전환과 복구

구현 후에는 시스템 프롬프트·채점 정책·코드·현재 선택 정보를 `systempromptbackup`에 보존하고 불변 CORE/H5와 복구 묶음을 준비한다.
호환 소비자 계약을 먼저 준비하고 실제 음성·영상 검사를 통과한 후보만 단계적으로 전환한다.
전환 중에는 진행 작업을 drain하며 원본 자료와 과거 결과를 유지한다. 롤백은 이전 H5·설정·표시 의미를 함께 복구한다.

이 문서의 산출물은 논문 모음과 실행 계획이다. 입술 채점의 가중치 확정, 데이터 모집·전문가 평가, 기능 구현·배포는 아직 수행하지 않았다. 이 문서 자체의 공유 PR·병합·소스 배포와 구분한다.
