# RunPod 영상·입술모양 분석 파이프라인

2026-09-29 **23:47~23:50 KST**에 실행 중인 RunPod의 코드·설정·자산을 읽어 정리한 배포 스냅샷이다. 설계 목표나 과거 실험을 현재 동작으로 간주하지 않는다. 상세 관측 범위와 파일 식별자는 [배포 근거](deployment-evidence.md)에 있다.

## 핵심 결론

- 영상만으로 발음 오류를 찾는 독립 모델이 아니다. Seungun 음성 근거에서 허용된 코칭 후보 **최대 3개**의 대표 음소 구간을 영상에서 관찰한다.
- ffmpeg로 영상·내장 음성을 검사하고, MediaPipe 입술 랜드마크, 영상 품질(QC), 음성–영상 동기화(A/V sync), 음소별 짧은 영상 구간 분석을 수행한다.
- 기본 4점 입 벌림 관찰에 더해, 별도 worker의 40점 후보를 AI Hub 68 기반 24점 매핑으로 변환하는 closed-beta 형상 경로가 설정되어 있다. 설정되어 있다는 것이 매 요청에서 모든 값이 나온다는 뜻은 아니다.
- 현재 GPT 코칭 경로는 수치·시간·실패 사유만 사용한다. `referenceStatus=NOT_VALIDATED`, `correctiveClaimsAllowed=false`이며, 개인별 입 벌림 교정이나 발음 정답 판정을 허용하지 않는다.
- 영상 분기 실패 시 유효한 음성 결과를 보존한다. 현재 코칭 경로의 최상위 `visualSupplement`는 null이고, 영상 결과는 `coaching.visual`에 들어간다.
