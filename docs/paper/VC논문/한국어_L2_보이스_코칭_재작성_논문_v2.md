## 초록

자동 발음 평가 점수의 상승이나 합성 참조음의 높은 자연스러움만으로는
제2언어 학습자의 발화가 실제로 더 잘 이해된다는 결론이 따라오지 않는다.
본 논문은 중급 이상 성인 한국어 L2 학습자의 격식체 읽기 발화를
대상으로, 음운·운율 진단, 조건부 참조 분포 보정, TTS 예시의 품질
적격성, 교육 효과 검증을 순차적인 증거 게이트로 연결하는 연구
프로토콜을 제안한다. 첫째, 표기와 발음 규칙에서 유도한 기대
canonical 음소열과 문맥상 허용되는 surface 발음 격자를 분리한다.
목표문 제약 음소 정렬과 목표문을 사용하지 않는 heard-as 음소 인식을
독립적으로 실행하고, 두 출력의 대치·삭제·삽입·병합을 비교한다. 운율은
자유 음소 인식으로 환원하지 않고, 목표문 기반 시간 정렬과
목표문 비의존 음향·운율 관측을 별도 경로로 둔다. 둘째, 동일 음성을
유지한 채 목표문을 제시·제거·교체·위약 처리하는 개입으로 목표 정보가
관측 발음을 기대형으로 복원하는 경향을 측정한다. 오류 보존과 함께
정상 또는 허용 발음을 오류로 과탐하는 역방향 위해를 동일 운영점에서
평가한다. 셋째, 다화자 앵커 음성을 절대적 표준이 아니라 격식체 낭독
조건에 한정된 참조 분포로 정의하고, 고정 크기 bank와 mean-kNN
비적합도를 사용한다. 인간 지각 라벨용 conformal prediction set과
실제 앵커용 reference acceptance region은 서로 다른 calibration
자료와 비적합도로 보정한다. 넷째, TTS 후보는 내용 보존, 음운·운율
적합성, artifact 및 blind 인간 평가를 통과한 경우에만 교육 실험
후보가 된다. 품질 적격성과 학습 성과 기반 선택은 결합하지 않는다.
마지막으로 자동 선택 점수, 독립 감사 점수, 인간 학습 결과와 운영
지표를 분리하고, 모든 선행 게이트를 통과한 동결 정책만 1주 지연
novel-sentence comprehensibility를 주 결과로 하는 무작위 대조
실험에 진입시킨다. 본 논문은 새로운 모델 성능, 인간 평가 완료 또는
교육 효과를 보고하지 않는다. 관측 근거, 사전등록 방법, 사람 검증
필요 항목과 조건부 후속연구를 분리하고, 실패 시 상위 주장을 닫는
판정 규칙을 결과 관측 전에 고정하는 것이 목적이다.

주제어: 자동 발음 평가, 오발음 탐지 및 진단, 한국어 L2, 조건부 참조
분포, conformal prediction, 선택적 예측, TTS, 교육 효과

# 1. 서론

자동 발음 평가(Automatic Pronunciation Assessment, APA)와
오발음 탐지 및 진단(Mispronunciation Detection and Diagnosis, MDD)은
대규모 학습자 발화에 일관된 피드백을 제공할 수 있다 [1,2]. 그러나
낮은 음성 인식 오류율, 높은 phone-level 분류 성능, 사람 점수와의
상관은 서로 다른 구성개념이다. 특히 읽기 과제에서 목표문을 입력받는
모델은 실제로 산출된 발음보다 화자가 말하려던 단어를 복원할 수 있다.
최근 영어 L2 자료의 분석은 현대 ASR의 language model과 문맥이
오발음을 의도된 단어로 교정하는 intent bias를 보일 수 있음을
보고하고, 음향 표면형을 보존하는 inference-time reranking을 강한
비생성 기준선으로 제시했다 [24]. 그 결과를 한국어로 그대로 옮길
수는 없지만, 목표 정보와 관측 음향을 분리해 감사해야 한다는 문제는
한국어 읽기 코칭에도 직접적이다.

한국어에서는 표기형과 발음형의 차이가 곧 오류가 아니다. 경음화,
비음화, 유음 관련 동화, 종성 중화와 문맥 변이가 존재하며, 운율은
accentual phrase(AP), intonational phrase(IP) 경계와 K-ToBI
boundary tone을 포함한다 [11,12]. 단일 canonical 열을 강제하면
허용 변이를 과탐할 수 있고, 목표문 없이 자유 인식만 하면 희소 오류나
경계 위치를 놓칠 수 있다. 따라서 두 경로는 서로를 대체하지 않고
상보적 실패를 드러내야 한다.

다화자 원어민 또는 전문 낭독 음성도 절대적인 발음 gold가 아니다.
뉴스 낭독은 격식체의 한 분포이며 방송사, 직군, 화자와 시점의 편향을
가진다. 참조 후보 수가 증가하면 minimum distance가 구조적으로
작아지는 set-size confound도 발생한다. 이에 본 논문은 고정 크기
참조 bank, mean-kNN 비적합도와 독립 보정을 사용해 “표준과의 거리”가
아니라 “정의된 조건부 분포에서의 적합성”을 추정한다.

TTS 예시 역시 자연스럽다는 이유만으로 교육적으로 유효하지 않다.
품질이 부족한 합성음은 학습자에게 노출하지 않아야 하지만, 품질
적격성을 통과했다는 사실도 학습 효과를 뜻하지 않는다. 본 연구는
TTS 품질 gate와 학습 성과 기반 선택을 분리하고, 자동 지표가 사람의
지연 학습 결과와 같은 방향으로 움직이는지를 독립적으로 감사한다.

본 논문의 기여는 성능 향상 보고가 아니라 다음 네 가지 검증 계약이다.

1. 기대 canonical, 허용 surface 격자와 인간 지각 실현형을 분리한
   두 경로 음운·운율 진단 및 고정 음성 목표문 개입을 정의한다.
2. 진단 라벨과 참조 분포에 서로 다른 real-only calibration 및
   conformal 객체를 부여하고, OOD·증거 불일치 시 abstention한다.
3. TTS 품질 적격성과 학습 성과 기반 선택을 분리하고, selection
   scorer·독립 audit scorer·인간 outcome·운영 지표를 분리한다.
4. 현재 근거 상태와 순차 gate, strongest baseline, 실패 시
   fallback을 사전 명시하여 자동 지표 개선이 교육 효과로 승격되는
   것을 차단한다.

# 2. 관련 연구와 적용 경계

## 2.1 APA, MDD와 자기지도 음성 표현

GOP는 phone posterior와 목표 phone을 비교하는 고전적 기준선이다 [1].
SpeechOcean762 같은 공개 영어 자료 [3]와 GOPT, HiPAMA, HierTFR,
HMamba 계열은 phone·word·utterance 또는 여러 평가 측면을 계층적으로
모델링했다 [4,6-9]. 자기지도 음성 표현도 발음 평가에 유용함이
보고됐다 [5]. 그러나 이 연구들의 주된 검증 언어와 라벨 체계는
한국어 표면 음운과 K-ToBI 운율을 직접 보장하지 않는다. 본 연구는
영어 논문의 수치를 한국어 기대치로 사용하지 않고, 동일한 한국어
split·평가 코드·자원 조건에서 재실행된 기준선만 비교 대상으로 둔다.

일반 ASR의 낮은 WER가 학습자의 산출을 더 잘 보존한다는 보장도 없다.
Park [24]는 영어 L2 corpora에서 의도된 단어로의 overcorrection을
분석하고, 독립 phone recognizer와 phonetic distance를 이용한
surface-faithful reranking을 제안했다. 본 논문은 그 용어와 결과를
한국어 사실로 전이하지 않는다. 대신 real-only target-free recognizer와
surface-faithful reranking을 목표문 편향 및 후속 합성 연구가 넘어야
할 강한 비생성 기준선으로 채택한다.

## 2.2 한국어 음운·운율과 허용 변이

한국어 진단은 canonical phone만으로 충분하지 않다. 기대열에서
문맥상 허용되는 경음화·동화·종성 실현을 전개한 surface lattice와,
실제로 들린 phone을 구분해야 한다. K-ToBI는 AP/IP와 경계 톤을
표현하지만, 자동 경계 또는 축약된 tone inventory만으로 전체 체계를
대표할 수 없다 [11,12]. 본 프로토콜은 희소 현상까지 무리하게 하나의
macro score로 압축하지 않고, 현상별 support와 불확실성을 함께
보고한다.

## 2.3 참조 분포, calibration과 선택적 예측

신경망 확률은 그대로 신뢰도로 해석할 수 없으므로 reliability,
Brier score와 ECE 같은 calibration 감사가 필요하다 [17].
Conformal prediction은 exchangeability 조건에서 유한 표본의
marginal coverage를 제공하는 도구이며 [18], 방언·L1·장비·방송사·
시점 이동에서 자동으로 보장되는 정확성은 아니다. 본 연구는
경험적 coverage와 set width를 함께 보고하고, 분포 이동 시
재보정 또는 abstention을 수행한다.

## 2.4 TTS 예시와 교육 효과

고변이 음성 훈련은 지각과 산출 사이의 연결에 조건부 이점을 가질 수
있지만 [13], 화자 수 또는 노출 다양성이 곧 학습 효과는 아니다.
합성 음성을 활용한 교정 피드백 연구도 존재하나 [14], TTS 자연스러움,
진단 점수와 지연된 novel-item 이해 용이성은 별도 outcome이다.
개인화 정책은 알려진 선택확률과 반사실 추정을 사용할 수 있지만
[15,16], off-policy 값은 동결 정책의 무작위 대조 실험을 대체하지
않는다.

## 2.5 조건부 후속연구의 근거 한계

교차언어 acoustic-to-articulatory inversion은 영어 센서 자료에서
학습한 SSL 표현을 네덜란드어로 전이할 가능성을 보였으나, 언어
불일치 성능 저하와 언어·장비·센서 배치의 교란이 남는다 [25].
이는 물리적 또는 보편적 조음 공간의 성립을 뜻하지 않는다. L2-GEN은
영어 L2 음소열과 합성 자료가 MDD의 데이터 희소성에 도움을 줄 수
있음을 보고했지만 [26], 인간 지각 label preservation, 정상 발음
역위해와 real-only calibration을 대신 검증하지 않는다. 따라서
다국어 조음 근사와 오류 합성은 현재 시스템의 달성된 개선이 아니라
별도 gate를 가진 후속 연구다.

# 3. 범위, 표기와 조작적 정의

## 3.1 직접 주장 범위

대상은 중급 이상 성인 L2 한국어 학습자의 격식체 읽기 발화다.
자유 대화, 아동, 입문·초급의 심한 왜곡, 지역 방언 교정, 원어민 딕션,
아나운서 직업 훈련, 말·언어 장애 진단과 치료는 직접 주장 범위가
아니다. 입문·초급 또는 심한 왜곡 자료는 별도 외부 타당도 연구에서만
다룬다. 목표는 지역 정체성이나 L1 억양의 제거가 아니라 정의된
과제에서의 이해 용이성과 학습 가능한 음운·운율 대조다.

## 3.2 기대형, 허용형과 인간 지각형

발화 음성은 \(x\), 목표문과 발음 문맥은 \(u\), 표기·사전·규칙에서
유도한 기대 canonical 열은

\[
c=(c_1,\ldots,c_J)
\]

로 둔다. 각 위치의 문맥상 허용 surface phone 집합은
\(\mathcal A_j(c,u)\), 전체 허용 pronunciation lattice는
\(\mathcal L(c,u)\)다. 집합에는 전문가 지침으로 승인된 동화,
종성·경계 변이와 방언 허용형을 포함하되, 통계적으로 자주 나타난다는
이유만으로 모든 변이를 자동 승인하지 않는다.

독립 청취자의 1차 prompt-blind 지각 분포와 hard label은

\[
q_H^{\mathrm{blind}}(y\mid x), \qquad
y_H^{\mathrm{blind}}=\arg\max_y q_H^{\mathrm{blind}}(y\mid x)
\]

로 둔다. 이후에만 목표문·허용 문맥을 공개해 context-aware
adjudication \(q_H^{\mathrm{ctx}}(y\mid x,u)\)를 별도로 만든다.
목표문 복원 편향의 주 분석과 진단 calibration에는
\(q_H^{\mathrm{blind}}\)를 사용하고, \(q_H^{\mathrm{ctx}}\)는 허용형
판정·불일치 설명·민감도 분석에만 사용한다. 생성기 의도, target JSON
또는 자동 TextGrid 표기는 어느 인간 분포도 대신하지 않는다.

## 3.3 두 경로 음소 진단과 편집 정렬

목표문 제약 경로의 posterior와 hard output은

\[
p_{\mathrm{tgt}}(y\mid x,c,u),\qquad
\hat y_{\mathrm{tgt}}
\]

이고, 목표문을 보지 않는 heard-as 경로는

\[
p_{\mathrm{free}}(y\mid x),\qquad
\hat y_{\mathrm{free}}
\]

다. 두 열과 \(\mathcal L(c,u)\)를 정렬해 대치 \(S\), 삭제 \(D\),
삽입 \(I\), 다대일·일대다 병합 또는 분할 \(M\) 사건을 만든다.

\[
\mathcal E=
\operatorname{Align}
\bigl(\hat y_{\mathrm{tgt}},\hat y_{\mathrm{free}},
\mathcal L(c,u)\bigr),\qquad
\mathcal E_j\in\{S,D,I,M,\mathrm{match},\mathrm{uncertain}\}.
\]

삭제·삽입·병합은 빈 phone 또는 span 사건으로 평가하며, 단일 phone
exact-match 분모에 억지로 넣지 않는다. 정렬 신뢰도
\(C_{\mathrm{align}}\)가 낮으면 이후 증거가 강하더라도 진단을
확정하지 않는다.

## 3.4 운율의 두 관측 경로

운율은 target-free phone recognition과 동일한 문제로 취급하지 않는다.
목표문과 정렬을 이용해 AP/IP 후보 위치 및 구간을 추출하는
\(r_{\mathrm{align}}(x,c,u)\)와, 목표문 없이 F0·에너지·지속시간·쉼에서
관측하는 \(r_{\mathrm{obs}}(x)\)를 분리한다. 두 경로가 경계 위치,
boundary tone 또는 말속도 방향에서 충돌하면 강한 교정을 생성하지
않고 재녹음·보류로 전환한다.

## 3.5 목표문 유도 expected-form restoration

“Canonical Attraction Bias”를 확립된 한국어 표준 용어로 주장하지
않는다. 본 연구에서는 목표 정보가 음향이 같은 상태에서 기대형 또는
허용형으로 출력을 이동시키는 현상을 target-induced expected-form
restoration으로 조작화한다. \(t\)는 target-on, target-drop,
target-swap, sham 중 하나다. 아래 위치별 지표의 주 분석 단위
\(j\in\mathcal J_{SM}\)은 독립 정렬자가 일대일 match 또는 substitution으로
판정한 위치로 제한한다. 삭제·삽입·병합/분할은 빈 기호와 span을 가진
별도 event로 정의해 event precision·recall, 경계 overlap과 현상별
confusion을 보고하며, 아래 phone-position 분모에 넣지 않는다.

\[
B_{\mathrm{exp}}(t)
=P\!\left(\hat y_t=c_j
\mid y_H^{\mathrm{blind}}\notin\mathcal A_j(c,u),
 j\in\mathcal J_{SM}\right),
\]

\[
B_{\mathrm{allow}}(t)
=P\!\left(\hat y_t\in\mathcal A_j(c,u)
\mid y_H^{\mathrm{blind}}\notin\mathcal A_j(c,u),
 j\in\mathcal J_{SM}\right).
\]

주된 기제 검정은 관찰 비율 하나가 아니라 고정 음성의 paired effect다.

\[
\Delta B_{\mathrm{allow}}
=B_{\mathrm{allow}}(\mathrm{on})
-B_{\mathrm{allow}}(\mathrm{drop/swap}),
\]

여기서 drop/swap은 사전등록된 대조 조건별로 별도 보고한다.
Sham은 target의 의미는 유지하되 형식·길이·처리 절차만 바꿔 단순
입력 존재 효과를 통제한다.

오류 보존의 hard 및 soft 지표는 다음과 같다.

\[
\mathrm{EPR}
=P(\hat y=y_H^{\mathrm{blind}}
\mid y_H^{\mathrm{blind}}\notin\mathcal A_j,
 j\in\mathcal J_{SM}),
\]

\[
\mathrm{EA}_{q}
=\mathbb E\!\left[
\sum_y q_H^{\mathrm{blind}}(y\mid x)p_{\mathrm{free}}(y\mid x)
\mid y_H^{\mathrm{blind}}\notin\mathcal A_j,
 j\in\mathcal J_{SM}
\right].
\]

\(\mathrm{EA}_{q}\)는 recall이 아니라 두 분포의 soft expected agreement다.
반대 방향 위해는 허용 발음의 false rejection이다.

\[
B_{\mathrm{err}}
=P(\hat y\notin\mathcal A_j
\mid y_H^{\mathrm{blind}}\in\mathcal A_j,
 j\in\mathcal J_{SM}).
\]

\(B_{\mathrm{allow}}\)를 낮추면서 \(B_{\mathrm{err}}\)를 높인 모델은
개선으로 판정하지 않는다. 모델 비교는 real-correct 자료에서
\(B_{\mathrm{err}}\) 또는 abstention coverage를 맞춘 운영점, 그리고
전체 risk-coverage 곡선에서 수행한다. 새 첨부 자료가 제안한
단일 임계 비교는 이 원칙에 맞지 않아 채택하지 않는다.

## 3.6 참조 비적합도와 두 conformal 객체

고정 크기 \(K\)의 조건부 실제 앵커 bank를 \(\mathcal R_K(c,u)\),
표현을 \(\phi(x,c,u)\), 최근접 \(k\)개를 \(\mathcal N_k\)라 하면
참조 비적합도는

\[
a_{\mathrm{ref}}(x;c,u)=
\frac{1}{k}\sum_{r\in\mathcal N_k(x;\mathcal R_K)}
d\bigl(\phi(x,c,u),\phi(r,c,u)\bigr)
\]

다. \(K\), 총 음성시간과 화자 수를 통제하지 않은 minimum-distance
비교는 주 분석으로 사용하지 않는다.

진단 label set은 독립적인 실제 인간 calibration 자료
\(\mathcal C_{\mathrm{diag}}\)의 prompt-blind 단일 adjudicated phone
\(y_i^{\mathrm{blind}}\)에 한해

\[
s_i^{\mathrm{diag}}=1-p_{\mathrm{free}}(y_i^{\mathrm{blind}}\mid x_i),
\quad
k_{\alpha}=\left\lceil(n_{\mathrm{diag}}+1)(1-\alpha)\right\rceil,
\quad
\hat q_{1-\alpha}^{\mathrm{diag}}=s_{(k_{\alpha})}^{\mathrm{diag}},
\]

\[
\Gamma_{\alpha}^{\mathrm{diag}}(x)
=\{y:1-p_{\mathrm{free}}(y\mid x)
\le \hat q_{1-\alpha}^{\mathrm{diag}}\}
\]

로 보정한다. 반면 참조 적격 영역은 held-out 실제 앵커
\(\mathcal C_{\mathrm{ref}}\)에서

\[
s_i^{\mathrm{ref}}=a_{\mathrm{ref}}(x_i;c_i,u_i),
\quad
k_{\beta}=\left\lceil(n_{\mathrm{ref}}+1)(1-\beta)\right\rceil,
\quad
\hat q_{1-\beta}^{\mathrm{ref}}=s_{(k_{\beta})}^{\mathrm{ref}},
\]

\[
\mathcal G_{\beta}^{\mathrm{ref}}
=\{x:a_{\mathrm{ref}}(x;c,u)
\le \hat q_{1-\beta}^{\mathrm{ref}}\}
\]

로 보정한다. 여기서 order statistic의 index가 calibration 크기를
넘는 극단 설정은 허용하지 않는다. 교환가능성 아래의 finite-sample
marginal coverage 주장은 위 단일-phone 진단 객체에만 한정한다.
soft-label, D/I/M event·span과 운율용 nonconformity 및 coverage는
별도 사전등록 전까지 TBD다. 두 calibration set, score와 coverage
claim은 서로 교환하지 않는다. 합성 자료는 어느 calibration에도
들어가지 않는다.

## 4.3 분할과 누수 방지

학습자 자료는 learner·speaker·session·prompt·sentence·device와 원본
음성 lineage 단위로 분리한다. 동일 원본에서 파생된 구간, 재합성본,
정상·오류 변형은 하나의 split group에 묶는다. L1-disjoint,

앵커 자료는 speaker·script·article·broadcaster·time을 분리하고,
reference selection에 사용한 발화는 calibration 또는 challenge
coverage 산출에 재사용하지 않는다. 향후 합성 자료는 train 또는
stress-test에만 허용하며 final real test, human primary test,
diagnostic calibration, conformal calibration, reference calibration,
교육 효과 평가에는 포함하지 않는다.

## 4.4 주석 품질

주석은 자동 G2P·정렬 후보 생성, 두 평가자의 독립 blind 청취,
confidence와 대안 label 보존, 불일치 adjudication, 무작위 재주석
순으로 수행한다. Cohen’s kappa 또는 Krippendorff’s alpha는
범주형 phone·오류에, ICC는 연속·등간 평정에 사용한다. 합의 목표값,
범주별 최소 support와 재교육 규칙은 pilot을 본 뒤 main annotation
전에 사전등록한다. support가 부족한 오류군은 전체 평균에 흡수하지
않고 unknown으로 남긴다.

## 5.1 음운·운율 진단

목표 제약 경로는 위치 정보를 제공하되 expected-form 복원 위험을
가진다. 자유 경로는 관측 표면형을 보존할 가능성이 있지만 희소 phone,
잡음과 짧은 구간에서 불안정할 수 있다. 두 경로의 합의가 곧 정답은
아니며, 독립 인간 gold에서 각 오류를 조건부로 추정한다.

구간별 증거는 phone posterior, reference margin, VOT, 후행 모음 F0
onset, closure, burst, frication, duration 같은 명시적 cue,
alignment confidence와 OOD score를 병렬로 보존한다. 한국어 평음·경음·
격음을 voiced/unvoiced 또는 aspiration 한 축으로 축약하지 않는다.
AP/IP와 9개 boundary tone은 phone head와 별도 output·loss·metric을
가진다.

## 5.2 관찰 가능 시각 증거

선택적 입술 영상은 양순 폐쇄, 입술 둥글림·퍼짐, aperture와 timing
같이 카메라에서 관찰 가능한 자질에만 사용한다. 영상만으로 혀,
연구개, 성문 상태 또는 정확한 physical articulation을 단정하지
않는다. 출력은 compatible, incompatible-candidate, uncertain,
visually-unobservable, tracking-failed, sync-failed를 구분한다.
영상이 없거나 품질 gate에 실패하면 audio-only 경로로 안전하게
fallback한다. OLKAVS [27] 같은 한국어 audio-visual 자료는 사전학습
후보일 뿐, L2 오류 또는 혀·후두 sensor gold가 아니다.

## 5.3 증거 결합과 제한형 피드백

증거 결합기는 각 원시 점수를 소실시키지 않고 상태 객체를 만든다.
다음 중 하나이면 진단을 확정하지 않는다.

\[
C_{\mathrm{align}}<\tau_a
\;\lor\;
S_{\mathrm{OOD}}>\tau_o
\;\lor\;
|\Gamma_{\alpha}^{\mathrm{diag}}(x)|>\tau_s
\;\lor\;
\text{path/evidence disagreement}.
\]

\(\tau_a,\tau_o,\tau_s,\alpha\)는 모두
\([\mathrm{TBD\_PREREGISTRATION}]\)이며 임의 값으로 채우지 않는다.
전문가 KB는 승인된 현상·관찰 cue·연습 지침을 evidence ID에 연결한다.
언어 모델을 사용할 경우 KB가 만든 directive의 표현만 담당하며,
새 원인·점수·조음 위치를 생성할 수 없다. 출력 후에는 각 문장이
허용 evidence와 연결되는지 fidelity 검사를 수행한다.

## 5.4 조건부 참조 bank

참조 구축은 다음 순서를 따른다.

1. 권리·동의·schema·음질·화자 metadata를 실사한다.
2. canonical·surface phone, AP/IP, boundary tone과 허용 변이를
   두 주석자와 adjudicator가 주석한다.
3. speaker·broadcaster·article·time을 분리한 후보 pool을 만든다.
4. 고정 \(K\), 화자당 상한과 총 시간을 맞춘 random bank와
   diversity-aware bank를 각각 동결한다.
5. held-out 실제 anchor로 reference acceptance region을 보정한다.
6. out-of-domain style, 새 장비와 새 시점에서 coverage 열화 및
   재보정 trigger를 감사한다.

참조 적합도는 격식체 낭독 조건에서의 분포적 근접성이지 언어 능력,
사회적 가치 또는 유일한 “좋은 한국어”의 점수가 아니다.

## 5.5 TTS 품질 적격성과 예시 선택

TTS 후보의 품질 벡터는 naturalness, intelligibility, phone fidelity,
prosody appropriateness, artifact와 모방 적절성을 포함한다.
자동 내용 일치·clipping·noise·license gate를 통과한 뒤, 생성기와
조건을 모르는 평가자가 동일 텍스트·유사 속도의 실제 anchor와
비교한다. 비열등성 margin, 평가자 수와 합의 절차는 pilot과
이해관계자 협의 뒤 main test 전에 사전등록한다.

적격성 통과 후보만 exemplar pool에 들어간다. 초기 정책은 static
high-quality 또는 알려진 확률의 random-diversity다. Outcome-aware
정책은 학습자 로그가 충분해진 뒤에만 학습하며, 선택확률, 후보군,
정책 버전과 노출 이력을 기록한다. 정책 학습과 confirmatory RCT
사이에는 동결선을 둔다.

# 7. 평가와 통계 분석

## 7.1 공정 비교

각 모델에는 합리적인 원 설정을 허용하는 best-available 비교와,
실제 학습 데이터량, parameter 범위, update step, GPU-hour,
augmentation, decoding, calibration, tuning trial과 seed를 가능한
범위에서 맞춘 resource-matched 비교를 모두 수행한다. 성공 run만
선택하지 않고 실패·중단 run과 checkpoint 선택 규칙을 보고한다.

RQ1은 phone event와 prosody event를 분리한다. Phone에는 S/D/I/M
classwise precision·recall·AUPRC, macro-AUPRC, confusion matrix,
alignment error propagation을 사용한다. AP/IP에는 boundary tolerance별
F1, 9개 tone에는 support와 confusion을 보고한다. 전체 평균과 함께
L1·숙련도·phone·문맥별 worst-group을 제시한다.

RQ2는 같은 음성에 대한 paired target intervention으로 분석한다.
모델별 threshold가 다를 때는 real-correct \(B_{\mathrm{err}}\) 또는
coverage를 맞춘 뒤 hard EPR, soft \(\mathrm{EA}_q\)와
\(B_{\mathrm{allow}}\)를 비교하고, risk-coverage curve를 함께
공개한다. 이 위치별 비교는 \(\mathcal J_{SM}\)에 한정하며 D/I/M은
별도 event·span 분석으로 보고한다. Target-free 경로의 swap
sensitivity가 0에 가까워야 한다는 가설은 사전등록하되, 구현·수치
달성을 전제하지 않는다.

RQ3은 ECE의 binning 방식, Brier score, NLL, reliability diagram,
경험적 conformal coverage와 prediction/acceptance width를 함께
보고한다. Marginal coverage를 subgroup 보장으로 확대 해석하지 않는다.
분포 이동이 감지되면 재보정 전까지 abstention 범위를 확대한다.

## 7.2 TTS와 정책 평가

RQ4의 인간 평가는 실제·TTS 조건과 generator를 blind 처리하고
평가자 random effect를 포함한다. 합격 여부는 평균 MOS 하나가 아니라
내용, intelligibility, phone, prosody, artifact의 공동 gate로
결정한다.

RQ5의 logged pilot은 propensity와 overlap을 감사하고, direct method,
inverse propensity weighting과 doubly robust 추정의 민감도를 비교한다.
Extreme weight와 clipping 민감도를 보고하며 overlap이 부족한 영역의
정책값을 추정하지 않는다. Pilot 결과는 confirmatory effect가 아니다.

동결 RCT의 primary model은 예를 들어 다음과 같은 mixed-effects
구조를 사용한다.

\[
Y_{ijsr}=\beta_0+\beta_1\mathrm{Post}_s+
\beta_2\mathrm{Arm}_i+
\beta_3(\mathrm{Post}_s\times\mathrm{Arm}_i)
+u_i+v_j+w_r+\epsilon_{ijsr},
\]

여기서 \(u_i\), \(v_j\), \(w_r\)는 각각 learner, sentence, rater
random intercept다. 필요하면 learner별 time slope를 추가한다.
Primary contrast, ITT, 결측 처리, 다중 비교 보정과 subgroup
interaction은 confirmatory data를 보기 전에 고정한다. 표본 수는
근거 없는 고정 숫자가 아니라 pilot의 분산·ICC·dropout과 교육적
minimum important difference를 이용한 simulation-based power
analysis로 결정한다.

## 7.3 Goodhart 감사

다음 네 흐름은 같은 scorer로 합치지 않는다.

1. Selection scorer: 어떤 feedback·exemplar를 제시할지 결정한다.
2. Audit scorer: 선택 정책과 분리된 backbone·label·holdout으로
   자동 품질을 감사한다.
3. Human outcome: blind 이해 용이성·intelligibility·전문가 평가를
   측정한다.
4. Operational metric: latency, 실패율, completion, 비용과 부담을
   측정한다.

선택 점수만 오르고 audit·human이 변하지 않으면 정책 scorer
최적화로, selection과 audit가 오르지만 human이 변하지 않으면
자동 construct 불일치로, human이 하락하면 위해 또는 reward
hacking으로 해석한다.

# 9. 조건부 후속연구 A·B와 System C

이 절은 현재 방법의 구현 또는 성능 주장이 아니다. 근거 감사의
결론은 “단계적 연구 프로그램”이며, 현재 원고의 중심 RQ를 A·B가
대체하지 않는다.

## 9.1 연구 B: 목표문 편향과 오류 보존 연구를 우선

첫 후속연구는 fixed-audio target intervention으로 expected-form
restoration을 먼저 확인하고, real-only target-free recognizer와
surface-faithful reranking을 구축한다. 오류 합성은 그 뒤에만
검토한다. 비생성 cue editing, segment replacement, acoustic/codec
editing 후보는 blind perceived-phone 전사, S/D/I/M, 내용·화자·비표적
운율 보존과 artifact 감사를 통과한 경우에만 train-only로 사용한다.
정상 발음도 같은 생성기로 재합성한 symmetric-resynthesis control과
generator-disjoint test로 “생성 흔적=오류” shortcut을 감사한다.

합성기 의도 label은 gold가 아니며, family별 support가 부족하면
unknown이다. Calibration, final real test, primary human gold와
교육 평가는 항상 real-only다. 합성 arm이 real-only
surface-faithful reranking을 넘지 못하거나 \(B_{\mathrm{err}}\),
calibration 또는 worst-group을 악화시키면 합성 채택을 중단한다.

## 9.2 연구 A: claim-limited Level-B 보조 파일럿

다국어 EMA·UTI·EPG·rtMRI는 같은 관측값이 아니며, corpus·language·
speaker·sensor가 함께 바뀌면 독립 disentanglement를 식별할 수 없다.
따라서 언어·화자·센서 metadata는 conditioning과 층화 변수로만
사용하고, universal 또는 physical articulatory space를 주장하지
않는다. 독립 자원이 있을 때만 sensor-specific teacher와 공통 자질
ontology가 resource-matched multilingual acoustic baseline보다
held-out sensor·speaker 및 한국어의 관찰 가능한 조음 자질과 실제
MDD에 증분 가치를 주는지 Level-B auxiliary pilot로 평가한다.
한국어 평·경·격의 VOT·F0 onset과 명시적 음향 cue는 대체하지 않는다.
직접 grounding, 한국어 추가 가치 또는 안전 gate가 실패하면 A는
내부 보조 특징으로 축소하거나 종료한다.

## 9.3 System C의 개방·종료 규칙

통합은 A와 B의 결과를 단순 병합하는 논문이 아니다. 다음 네 arm을
동일 real data·calibration·compute 조건에서 비교할 수 있을 때만
연다.

1. real-only,
2. real + human-approved acoustic/codec synthetic,
3. real + human-approved A-latent synthetic,
4. real-only + surface-faithful reranking.

A-latent가 실제로 사용 가능하지 않으면 0점으로 채우지 않고
unavailable로 기록한다. A-latent 합성이 acoustic/codec 합성과
reranking을 모두 넘지 못하거나 정상 발음, real calibration,
worst-group 중 하나를 악화시키면 System C를 종료한다. 이는 방향 B의
편향 측정 연구까지 폐기한다는 뜻이 아니다.

# 10. 윤리, 공정성 및 안전

뉴스·전문 낭독을 조건부 참조로 쓰는 것은 표준어 이데올로기와 직군
편향 위험을 가진다. 시스템은 지역·사회 방언, 허용 allophone 또는
L1 억양을 자동으로 오류 처리하지 않는다. L1은 오류를 결정하는 고정
accent token이 아니라 층화·불확실성 분석 변수다.

잘못된 피드백은 학습자가 올바른 발음을 과도하게 수정하도록 만들 수
있다. 낮은 alignment·calibration confidence, OOD, 경로 또는 증거
불일치에서 abstain하고, 반복 실패 시 같은 교정을 강화하지 않는다.
사람 검토, 이의 제기와 rollback 경로를 둔다. “혀가 정확히 어느
위치에 있었다” 같은 물리적 설명은 직접 sensor gold 없이는 금지한다.

음성·얼굴 영상과 조음 센서는 생체정보다. 신규 수집에는 동의, 목적,
보존기간, 철회, 가명화, 원음·embedding 분리 보관, 제3자 TTS/API
전송 고지와 접근 최소화를 적용한다. 화자 정체성을 보존한 오류
합성은 사칭 위험이 있으므로 승인된 연구 환경에서만 다루며 provenance,
접근통제와 파생물 폐기 정책을 둔다.

참여자 탐색은 적격·안전 후보군 안에서만 수행하고 노출 횟수와 세션
시간을 제한한다. 교육 실험은 윤리심의와 사전등록 뒤 시작한다.
본 시스템을 의료·임상 진단 또는 치료 도구로 표현하지 않는다.

# 11. 한계

첫째, 본 논문은 결과 없는 연구 프로토콜이다. 두 경로, 인간
calibration, 조건부 참조 bank, TTS 적격성과 교육 효과는 모두
검증 대상이다.

둘째, 직접 범위는 중급 이상 성인의 격식체 읽기다. 입문·초급의 심한
왜곡, 자유 대화, 장기 습득과 다른 L1로의 일반화는 별도 연구가
필요하다.

셋째, 현재 real L2 inventory의 realized phone과 오류 tag는 독립
지각 gold가 아니다. Gold가 없는 상태에서 silver dev 결과를 최종
성능으로 승격할 수 없다.

넷째, 뉴스·전문 낭독 후보는 격식체의 일부 분포이며 화자 다양성이
스타일 다양성을 보장하지 않는다. 권리·manifest·주석 실사 전에는
후보일 뿐이다.

다섯째, conformal coverage는 calibration 분포와 exchangeability에
조건화된다. L1, 장비, 방송사, 시점과 말하기 style이 이동하면 보장이
약해질 수 있다.

여섯째, selection scorer와 audit scorer가 다른 architecture여도
pretraining data와 label을 공유하면 상관된 오류가 남는다. 인간
평가를 대체할 수 없다.

일곱째, outcome-aware 정책은 많은 종단 관측과 overlap을 요구한다.
데이터가 부족하면 static 또는 random-diversity가 더 정직한
운영 선택이다.

여덟째, 후속연구 데이터와 문헌 중 일부는 아직 후보 상태다. 공식
primary source, license와 실제 artifact로 확인되지 않은 표본수,
threshold 또는 달성형 성능 문구는 본 원고의 주장·gate로 사용할 수
없다.

# 12. 결론

본 논문은 한국어 L2 격식체 읽기 코칭을 하나의 end-to-end 성능
주장으로 제시하지 않고, 진단 타당도, 목표문 유도 복원, 조건부 참조
보정, TTS 품질 적격성, 운영 안전과 지연 교육 효과 사이의 증거
의존성을 고정한다. 기대 canonical, 허용 surface와 인간 지각형을
분리하고, 목표 제약·target-free 음소 경로와 운율의 정렬·관측
경로를 병렬로 유지한다. 진단과 참조에는 서로 다른 real-only
conformal 보정을 사용하며, OOD 또는 증거 불일치에서는 abstain한다.

현재 자료로 성능 개선, 품질 적격 참조 bank, 반복 코칭, 자기개선 또는
교육 효과를 결론 내릴 수 없다. 저장소 정본의 실행 순서는 P0 진단
강등 migration, P1 데이터·label·권리·split 실사, D07과
S104–S106 및 R00–R03의 분리된 병렬 준비, S107·C02·C03·R04,
S108 one-shot, S200–S203 독립 발음 검증, Loop B pilot, 그리고 모든
선행 gate를 통과한 동결 정책 RCT다. Loop C는 `closed_by_policy`를
유지한다. 오류 합성 연구 B는 별도 bias/method paper로 우선 검토하고,
다국어 조음 연구 A는 독립 자원이
있을 때 Level-B 보조 파일럿으로 제한한다. 두 축의 독립 추가 가치가
확인되지 않으면 System C를 열지 않는다. 이처럼 실패가 상위 주장을
자동으로 닫도록 설계하는 것이 본 프로토콜의 핵심 안전장치다.
