작성일: 2026-08-12

## 1. 총괄 판정

- 현재 PDF는 **단일 결과-이전 프로토콜 논문**으로 유지한다.
- RQ는 진단 → 목표문 편향 → 참조 calibration → TTS 적격성 →
  교육 효과의 순서로 계층화한다.
- 연구 방향 B는 **독립 bias/method 후속 논문을 우선**한다.
- 연구 방향 A는 독립 자원이 있을 때만 **claim-limited Level-B
  auxiliary pilot**으로 검토한다.
- System C는 A와 B의 독립 gate를 통과하고 네 arm에서 추가 가치가
  확인될 때만 열며, 그렇지 않으면 종료한다.
- 현재 시스템이 A/B/C로 개선됐다는 달성형 문장은 사용하지 않는다.

이 판정은 “현재 프로토콜 원고를 한 편으로 유지하는가”와 “A/B 후속
연구를 한 편으로 합치는가”를 구분한다. 전자는 단일 유지이고, 후자는
현재 분리다.

## 2. 입력 provenance와 사용 범위

| 입력 | 확인된 성격 | 사용 방법 | 사용하지 않은 방법 |
|---|---|---|---|

| 로컬 참고 PDF | APA, SSL, AV speech와 내부 청사진 | 기존 참고문헌과 설계 충돌 확인 | 최신 정본과 충돌하는 내부 청사진 수치를 복사 |

### 중요한 provenance 판정

최초 지침의 기준 논문 제목과 재작성 대상 PDF는 제목, 대상 숙련도와
핵심 연구질문이 다르다. 따라서 v2는 별도 입문·초급 논문의 달성
내용을 전제하지 않고, 보존 요구만 현재 프로토콜의 사전등록 확장
계약으로 반영한다.

## 3. Sol–Fable 토론 기록

### 3.1 완료된 Fable 5 Max 1차 토론

- 실제 CLI 모델: claude-fable-5
- effort: max
- 대상: 재작성 PDF 전체와 비민감 aggregate 상태 요약
- 핵심 Fable 반론:
  1. 현재 PDF의 기여 단위는 개별 RQ가 아니라 gate 사슬이다.
  2. 교육 outcome을 원고 밖으로 완전히 빼면 사전등록 가치와
     Goodhart 검정의 정당화가 약해진다.
  3. 문제는 RQ 숫자보다 실제·후보 데이터 축의 불일치, 두 경로와
     target intervention 부재, bandit 세부의 과잉이다.
- 공동 수용:
  1. 단일 프로토콜 원고 유지와 RQ 계층화.
  2. 71490 전체 수치는 관측 inventory에 한정하고, 71557은 현 Loop A/RQ3에서 제외하며, 추가 L1 자료는 실사 전 `blocked`로 둔다.
  3. 두 경로와 fixed-audio target intervention 신설.
  4. TTS 품질과 교육 효과 분리 보존.
  5. A/B는 핵심 방법이 아니라 claim-limited 후속연구.

### 3.2 Sol의 교정

1. 최종 RQ를 최초 사용자 계약에 맞춰 정확히 5개로 확정했다.
2. target-free phone recognition을 AP/IP·boundary tone에 그대로
   적용하지 않고 운율의 정렬 기반·목표 비의존 관측 경로를 분리했다.
3. diagnostic label set과 reference acceptance region에 서로 다른
   calibration set과 nonconformity를 부여했다.
4. “canonical reference bank” 대신 “품질 적격 조건부 reference
   bank”를 사용했다.
5. 구현 snapshot과 연구 결과 표를 분리하고 내부 dev 수치를
   본문에서 제외했다.
6. A/B/System C를 본문 9절의 조건부 후속연구로 격리했다.

### 3.3 추가 Council 첨부 후 재토론 상태

추가 첨부를 읽은 뒤 두 번째 Fable 5 Max 호출을 시도했으나 Claude
CLI가 HTTP 429와 “individual spend limit”을 반환했다. 제한을
우회하거나 다른 Claude 모델로 낮추지 않았다. 따라서 추가 첨부의
반영은 완료된 Fable 1차 합의와 기존 Sol–Fable A/B 토론의 결정
규칙 안에서만 수행했다. 최종 절별 Fable 재심은 사용 한도가
복구되기 전까지 미완료다.

### 3.4 Sol 독립 근거감사 반영

초안 뒤 독립 Sol 감사가 저장소 정본과 수식·도식의 충돌을 재검사했다.
그 결과 71557 후보 재개방을 철회하고, 서술 역할과 `repo_status`를
분리했으며, prompt-blind gold와 context adjudication, S/M 위치 지표와
D/I/M event·span 지표를 분리했다. 또한 soft 내적을 EPR로 부르지 않고
\(\mathrm{EA}_q\)로 고쳤고, conformal coverage를 단일 adjudicated
phone으로 제한했으며, calibration fit/apply 데이터 흐름과 정본 실행
순서를 교정했다. 이는 실증 gate 통과가 아니라 원고 내부 정합성
교정이다.

## 8. 문헌 검증 지도

### 본문에 추가한 1차 출처

- Park (BEA 2026): intent bias와 surface-faithful reranking의 영어
  근거. 한국어 효과로 외삽하지 않았다.
- Hao et al. (Interspeech 2024): cross-lingual AAI의 가능성과
  language-mismatch 한계. physical/universal 주장에 사용하지 않았다.
- Zhang et al. L2-GEN (Interspeech 2022): 합성 L2 phone sequence의
  MDD augmentation 가능성. human label preservation 증거로 사용하지
  않았다.
- Park et al. OLKAVS (ICASSP 2024): 한국어 audio-visual 자료의 존재와
  lip pretraining 후보. L2 오류·sensor gold로 사용하지 않았다.

### 추가 검증 전 사용하지 않은 항목

- Council의 2025–2026 preprint 및 검색 snippet 수치.
- Moonlight, CatalyzeX, SciSpace 등 2차 요약.
- 공식 card를 재확인하지 못한 AI Hub 71490 데이터명·version.
- SPARC/ARTI-6/FROST-EMA 등의 구체적 성능 수치와 배포 조건.
- 워터마크 shortcut 수치. 원리는 대칭 재합성 control로만 반영했다.
