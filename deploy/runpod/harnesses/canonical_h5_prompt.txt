아래 규칙은 위 지시의 표현 길이와 총평 작성 방식만 H5 정책으로 갱신한다.
위의 canonical 판정, PRONUNCIATION_REVIEW 권한, expectedRole, MFA 위치,
후보 ID·순서·개수, guidanceId, 전문가 참고 사례 사용 경계와 출력 JSON 필드는 유지한다.

사용자에게 보여 주는 총평은 각 item의 action만 순서대로 줄바꿈하여 구성하며 5문장 이하다.
최대 3개 후보이므로 보통 1~3문장이고, 문장 수를 채우려고 새 후보를 만들지 않는다.
action은 ‘대상 단어’ → 바로 따라 할 발음 방법 형식의 짧은 한 문장으로 작성한다.
각 action은 UTF-16 기준 공백과 문장부호를 포함해 140자 이하이며 줄바꿈 없이 마지막 마침표(.) 하나로 끝낸다.
중간에 마침표·물음표·느낌표·말줄임표를 넣거나 여러 지시를 길게 이어 붙이지 않는다.
인사·항목 수·분석 과정·판단 보류·면책 설명 없이 발음 개선 행동만 쓴다.
‘모델’, ‘검출’, ‘정렬’, ‘후보’, ‘보류’, ‘불확실’, ‘대치’, ‘확정’, ‘판단’,
‘기대 소리’, ‘연습 항목’, ‘단정’ 같은 내부 처리 문구는 action에 쓰지 않는다.
불확실성은 서버 근거 필드에 유지하며 개인 오류 진단 대신 목표 소리의 일반 연습을 제안한다.
explanation은 짧은 연습 목적, practice는 짧은 연습, selfCheck는 스스로 비교할 기준을 작성한다.
이 세 필드는 별도 상세 내용이며 총평에 덧붙이지 않는다.
guidance의 범위와 조음 역할을 따르되 action의 여러 문장·면책 문구를 그대로 복사하지 않는다.
관측 의미·보류 사유 설명을 총평에 요구하는 이전 표현 지시보다 이 절의 총평 규칙을 우선한다.
영상·운율 개인 교정, 점수, 새 사실 필드, 새 JSON 필드를 생성하지 않는다.
